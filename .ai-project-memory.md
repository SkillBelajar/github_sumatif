# AI Project Memory

**Project:** Aplikasi Asesmen Sumatif Mandiri Siswa (Kurikulum Merdeka)
**Stack:** Laravel 13, Octane, Inertia (Vue 3), Tailwind CSS, MySQL, Redis, Docker

## 5W1H
- What: Aplikasi ujian/asesmen digital formatif & sumatif per Tujuan Pembelajaran (TP).
- Who: Admin (Data view), Guru (Daftar mandiri, pembuat soal & penilai), Siswa (Peserta ujian tanpa login).
- Why: Memudahkan guru menjalankan asesmen Kurmer sesuai standar (TP, KKTP, umpan balik instan).
- Where: Browser (Mobile & Desktop) via Inertia Vue 3.
- When: Digunakan saat ujian (high concurrency via Octane & Redis).
- How: Guru daftar mandiri -> buat soal per TP -> rakit kuis -> siswa kerjakan via token -> nilai otomatis per TP & analitik.

## Catatan Teknis
- Container: app (PHP-FPM:9000) | web (Nginx:8088) | db (MySQL:3306) | redis (6379)
- Admin account: admin@admin.com / password
- Teacher account: daftar via /register (role=teacher, auto login redirect ke /teacher/dashboard)
- SubjectSeeder: 10 mapel default (Matematika, Bahasa Indonesia, dll.) — auto seed
- Route cache: hapus `bootstrap/cache/config.php` sebelum `php artisan test` (env override conflict)
- Footer versi dinamis via `$page.props.appVersion` (0.16)
- Guest cannot access teacher routes (redirect /login)
- Import soal: CSV via fgetcsv (fokus Pilihan Ganda). Template: GET /teacher/question-bank/template
- Panduan Pengguna: /panduan (route `panduan`, butuh login) — konten dinamis by role (`UserGuideController` + `Pages/UserGuide.vue`), akordion via `Components/Accordion.vue`
- Versi final "1.0 (Final)": `appVersion` di `HandleInertiaRequests.php` (sidebar/footer/landing/register/login) + `AssessmentController::VERSION` (halaman siswa tanpa login)
- Container stabil: RestartCount app/web/db = 0 (PHP-FPM, bukan Octane — Octane tak dipasang; task "pastikan stabil" terpenuhi tanpa Octane)
- Responsivitas: Attempt.vue mobile-first (max-w-3xl, sticky header, tombol 44px); tabel lebar pakai `overflow-x-auto` (Admin Dashboard, Reports/Results)
